How BEE works

  • Plan the night before, in 30‑minute blocks. Non‑negotiable.
  • Next day, tap Did it if you executed the plan for that block. That's 1 point.
  • If you drifted, tap Didn't and jot what you actually did — that's the data that makes next week's plan better.
  • Target: 80% effectiveness. Drucker's time log rarely got higher.
  • Blank blocks don't score. Only planned blocks count toward the ratio.

Google Sheet setup

BEE can push each day's log to a Google Sheet so you can track effectiveness across weeks and months.

  1. Create a new Google Sheet.

  3. Deploy → New deployment → Web app. Execute as Me, access Anyone. Copy the URL.
