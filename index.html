How BEE works

  • Plan the night before, in 15‑minute blocks. Non‑negotiable.
  • Next day, tap ✓ if you executed the plan for that block. That's 1 point.
  • Drifted? Tap ✗ and jot what you actually did — data for next week's plan.
  • Tap ▶ on a row (or in the floating pill) to start a 15‑minute focus timer with a bell.
  • Target: 80% effectiveness. Open Trends to see the curve.
  • Blank blocks don't score — only planned blocks count.

Cloud setup (Supabase)

BEE syncs across your devices via your own free Supabase project.

  1. Create a free account at supabase.com and start a new project.
  2. In the project, open SQL editor, paste the contents of supabase.sql from this repo, and run it.
  3. Go to Project Settings → API. Copy the Project URL and the anon public key.
  4. Paste both below, then sign in with your email.

Google Sheet setup

Optional: push each day's log to a Google Sheet via a small Apps Script.

  1. Create a Google Sheet.
  2. Extensions → Apps Script. Paste google-apps-script.js from this repo and save.
  3. Deploy → New deployment → Web app. Execute as Me, access Anyone. Copy the URL.
